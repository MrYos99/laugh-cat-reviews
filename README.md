One funny single-line one-star review written by a house cat about its human, under 200 characters — built for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
